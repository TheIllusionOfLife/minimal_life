# ALife Conference Full Paper 査読結果

## 対象論文
- **Title**: *Minimal Diagnostic Principles of Life: Criterion-Ablation and Observable Surrogate Selection in a Digital Ecosystem*
- **Submission type**: Full Paper

## 総評
本稿は、生命の7基準（細胞構成・代謝・恒常性・成長・生殖・刺激応答・進化）を1つのALifeシステムに統合し、アブレーションで機能的必須性を検証するという、野心的で意義の高い研究です。特に、単一基準アブレーションに加えて、ペアワイズアブレーション・段階的アブレーション・閾値感度・境界条件比較まで実施している点は強く評価できます。

一方で、**本稿の中核である「Criterion Reduction / Surrogate Analysis」節の図が提出版PDFで欠落（プレースホルダ表示）しており、主張の検証可能性と可読性を大きく損なっています**。また、削減分析は著者自身が認める通り統計的検出力不足（負の \(R^2\)、LASSO閾値未達）であり、現状では主張を強く置きにくいです。

## 評価（5段階）
- **独創性**: 4/5
- **技術的妥当性**: 3/5
- **実験設計・検証の厚み**: 4/5
- **明瞭性・提示品質**: 2/5
- **再現可能性**: 3/5
- **総合評価**: 2.5/5（Borderline, 弱いReject寄り）
- **査読者信頼度**: 4/5

## 長所
- 7基準を「functional analogy（動的プロセス・除去時劣化・フィードバック結合）」で統一的に定義し、検証可能な形に落としている。
- 単一アブレーションの効果は大きく、統計処理（Holm補正、効果量、ブートストラップCI）も明示されている。
- ペアワイズ相互作用、段階的（dose-response）アブレーション、閾値感度、トポロジー変更など、ロバスト性確認が豊富。
- 進化効果を短期・長期で分けて報告し、限界（open-ended evolution未達）も明示している。

## 主要な懸念点（Major Concerns）
1. **主節の図欠落（重大）**
   - PDF上で Figure 4/5 相当がプレースホルダ（`[fig crit stability]`, `[fig pca biplot]` など）になっており、Criterion Reduction / Surrogate Analysis の主張を視覚的に検証できません。
   - フルペーパー査読において、主要結果図の欠落は致命的です。

2. **Criterion reduction の根拠が弱い**
   - 著者自身が「全ての平均 \(R^2<0\)」「LASSO閾値未達」と記述しており、現段階では「探索的所見」の域を出ていません。
   - それにもかかわらず、要旨・結論で最小診断原理をやや強く主張しているため、主張強度と証拠強度の整合を改善すべきです。

3. **構成概念妥当性（construct validity）に未解決点**
   - 「基準を無効化すると生存が落ちる」こと自体が、設計上の依存関係を再確認している可能性を完全には排除できません。
   - sham・proxy・pairwiseは有用ですが、より強い反証としては外部系（別ALife基盤）での再現や、同等機能代替による因果切り分けが望まれます。

4. **進化基準の主張の一貫性**
   - 補足ではエネルギー指標で方向選択が非有意（H1失敗）である一方、本文で「適応」を強く主張する箇所があり、どの表現型に対する適応かを主本文で明確化すべきです。

## 軽微なコメント（Minor Comments）
- 自己評価表（他システム比較）は、採点者バイアス低減のため付録送りまたは主張の弱化が望ましい。
- 主要メトリクス（\(N_T\), AUC, lifespan）の因果的読み分けを、図キャプションでさらに明確にすると理解しやすい。
- 2,000-step と 10,000-step の効果量（特に evolution）で、どの従属変数に対する \(d\) かを本文中で毎回明記すると誤読を防げる。

## 著者への質問
1. Reduction/Surrogate節の図ファイル欠落は提出パッケージ由来の問題か、それとも版管理上のパス問題でしょうか？
2. 進化の「適応」を主張する主要表現型は何ですか（エネルギー以外を主張するなら、その主指標を本文の中心に据えるべき）？
3. Phase 2（\(\geq 100\)条件）で、事前登録済みの主要仮説・停止規則・主要評価指標は何ですか？

## 最終判定
**Weak Reject（ただし採択可能性は高い）**。

理由は、研究アイデアと実験設計は強い一方で、**現提出版では主要図の欠落と、削減分析の根拠不足により、フルペーパーとしての完成度が基準に届いていない**ためです。図欠落の修正と主張強度の適正化（探索結果の位置づけ明確化）がなされれば、次版で有力な採択候補になると考えます。

## 10点満点を狙うための改善案（複数）

以下は、現状の弱点を直接つぶし、**総合スコアを10/10相当まで引き上げる**ための現実的な改善パッケージです。

### 改善案A（最短ルート：提出品質の即時是正）
**目的**: 可読性・信頼性の減点を即時回復し、査読者の「読む前提」を満たす。

- Reduction/Surrogate節の欠落図を全て修正（プレースホルダを0件化）。
- 図パスを提出環境で再検証し、最終PDFで表示確認（Figure 4/5系を重点確認）。
- 要旨・結論の主張をエビデンス強度に合わせて調整（探索的結果は探索的と明示）。
- 2,000 step と 10,000 step の効果量について、各指標（何に対する \(d\) か）を明記。

**期待効果**: 明瞭性 2→4、再現可能性 3→4、総合評価の土台を回復。

### 改善案B（統計的説得力の強化：Reductionを主張可能にする）
**目的**: 「面白いが未確証」を「統計的に支持される」に転換する。

- Phase 2として条件数を拡張（目安: \(\geq 100\) 条件、可能なら 120–150 条件）。
- 事前登録を本文内で明示（主要仮説・主要評価指標・停止規則・補正方針）。
- 学習/検証/最終評価の三層分離を徹底（環境条件ごとの外部ホールドアウトを含む）。
- Negative \(R^2\) の原因診断を実施（モデル不適合・サンプル不足・目的変数設計）し、改善前後を比較提示。
- LASSO/Elastic Netに加え、Permutation test と感度分析を補助提示。

**期待効果**: 技術的妥当性 3→4.5、検証の厚み 4→5。

### 改善案C（構成概念妥当性の強化："設計依存"批判への先回り）
**目的**: 「作り込み依存の結果では？」という典型的反論を封じる。

- 同等機能の代替実装比較を増やす（現行2系統→3系統以上）。
- 可能なら第2プラットフォームでミニ再現実験（同一7基準テストの移植版）。
- 因果切り分けのための代替介入（同じエネルギー収支で機能のみ置換）を追加。
- 主要結論に対し「どの実験が何を反証するか」を1対1で表に整理。

**期待効果**: 技術的妥当性と再現可能性の同時向上、査読者の納得度上昇。

### 改善案D（進化主張の一貫性修正）
**目的**: H1非有意との整合を取り、進化の主張を強く・正確にする。

- 「エネルギー方向選択は不支持、ただし別表現型で適応」を主本文で明文化。
- 適応ターゲット候補（空間効率、再生産タイミング、境界維持効率）を主要解析に昇格。
- 世代別・環境別で selection differential / heritability を並列報告。
- 進化の主張を「短期生存必須」ではなく「長期適応寄与」に統一。

**期待効果**: 論理一貫性が改善し、反論耐性が高まる。

### 改善案E（提出物完成度の仕上げ）
**目的**: 最終的な査読体験を"減点のない状態"にする。

- 図表番号・参照・補足節参照（\S Sx）のリンク崩れを全点検。
- 再現手順を本文末に5行で要約（コマンド、シード、出力物、検証指標）。
- 自己評価比較表は本文でトーンダウンし、付録で根拠データを拡充。
- 主要主張ごとに「根拠図表」を明示するクレームマップを付録化。

**期待効果**: 明瞭性 4→5、再現可能性 4→5。

## 推奨実行順（採択率最大化）
1. **A（即時）**: 図欠落と主張整合を修正。
2. **D（即時〜短期）**: 進化主張を整流化。
3. **B（短中期）**: Reductionの統計的確証を獲得。
4. **C（中期）**: 構成概念妥当性を補強。
5. **E（最終）**: 提出品質を仕上げ。

この順に実施できれば、現行の弱点（図欠落・統計不足・主張過多）を順に解消でき、**総合10/10評価に到達可能な原稿品質**に近づきます。
